# MS Location Tracking Service

This project is an AWS Lambda service for location tracking.

## Setup

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure your environment variables in AWS SSM.
4. Deploy the service using the Serverless Framework.

## Usage

The service exposes an API that can be accessed via HTTP requests. Use the appropriate endpoints as defined in the serverless.yml file.
